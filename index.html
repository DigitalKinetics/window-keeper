Window Keeper – Privacy Policy

Effective 5 October 2026 · Published by Yash Kanni

Window Keeper is a Chrome extension that lets you name browser windows, keeps the tabs of those windows saved, and reopens them after they have been closed. This policy explains what information the extension handles. The short version: it stays on your device and is never sent to the developer or anyone else.

Information the extension handles

For each window you choose to name, Window Keeper reads and saves:

  • the name you typed;
  • the address (URL), title and site-icon address of each tab in that window, whether the tab is pinned, and the order of the tabs;
  • the name, colour and collapsed state of any tab groups in that window.

Windows you do not name are not saved. Private (incognito) windows are never saved. The extension does not read page content, form entries, passwords, cookies or browsing history beyond the open tabs of the windows you named.

Where it is stored

Everything is stored locally in your browser using Chrome's extension storage (chrome.storage.local for saved windows, chrome.storage.session for which open window currently has which name). It is not synced to your Google account and is not uploaded anywhere.

What is shared

Nothing. Window Keeper has no server, no account system, no analytics, no advertising and no tracking, and it does not sell, rent or share data with anyone. It does not load or run code from outside the extension.

One detail for completeness: to show a website's small icon next to a tab in the list, the popup loads that icon from the address Chrome already reported for the tab. That request goes directly from your browser to the website you were already visiting, in the same way the website's own tab does. It does not pass through the developer or any third party.

Export and import

If you use Export, the extension creates a file containing your saved windows and tabs and your browser downloads it to your device. If you use Import, it reads a file you select. These actions happen only when you start them.

Permissions

  • tabs – to read the tabs of windows you named and to reopen, order and pin tabs when you restore a window. Chrome describes this permission as "read your browsing history"; the extension uses it only for the purpose above.
  • tabGroups – to save and recreate tab groups.
  • storage and unlimitedStorage – to keep your saved windows on your device without hitting the default storage limit.
  • alarms – to refresh the saved tabs of named windows once a minute while the browser is open.

Retention and deletion

Saved windows stay on your device until you remove them. Use the ✕ button next to a window in the extension to delete it and its saved tabs, or clear the extension's data in Chrome. Uninstalling the extension deletes everything it stored.

Children

Window Keeper is a general-purpose tool and is not directed at children.
